1. Matching models (tape + laser, BLE, angle sensor), specs and photos

3. BLE protocol documentation or SDK
4. Sample price and lead time to Tashkent
5. Certifications: CE, FCC, RoHS, laser class 2 (IEC 60825-1); accuracy spec
6. Production lead time and warranty
