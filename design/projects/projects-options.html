Three ways to design the Projects screen

All three use the same four sample projects, in Uzbek Latin. Because the app is for brickmasons, every design shows the net wall area (walls minus doors and windows) instead of floor area, plus how much of the measuring is done.

Empty thumbnailsEvery card shows the same empty rectangle, so it says nothing about the project.
Space on empty values"Smeta 0 so‘m" and "Taklif chiqarilmagan" take two lines on every new project.
The wrong areaFloor area is shown, but a brickmason prices by wall area.
Six filter chipsThey run off the screen, and the stages with 0 projects still take space.
A

Compact list

One dense row per project, grouped by when you last worked on it. A simple Active / Done switch replaces the six chips. Fits about seven projects on one screen.
