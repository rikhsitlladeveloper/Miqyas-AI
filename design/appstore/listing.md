# METRX — App Store listing texts (v1.0)

Paste each block into App Store Connect → the app → the version → the language. Counts are Unicode characters (what App Store Connect counts) and were checked by a script against Apple’s limits: name 30, subtitle 30, promotional text 170, description 4000, keywords 100, What’s New 4000.

Rules kept: keywords are comma-separated with no spaces after commas, don’t repeat the app name, and don’t repeat words already in the subtitle (Apple indexes name, subtitle and keywords together, so repeating wastes space). No other brands or app names are used. Uzbek Latin uses ‘ (U+2018) in o‘ and g‘, and ’ (U+2019) for the apostrophe (ta’mir, App Store’da).

## Notes and open choices

1. **Uzbek as a store language.** If App Store Connect has no Uzbek localization, the usual choices are:
   - **(a) Recommended:** make **Russian** or **English** the primary language and add the other one; put the short Uzbek promotional text at the top of the Russian description (Uzbekistan users read both). The Uzbek texts here stay ready for when Apple adds Uzbek.
   - (b) Use the English (U.K.) slot for the Uzbek texts. This works technically, but Apple expects each localization’s metadata to be in that language, so it is a review risk. Not recommended.
2. **Keywords and the ‘ sign.** People often type o'lchash with a plain ' when they search. The Uzbek keywords avoid o‘/g‘ words for that reason (the subtitle already covers *lazer, o‘lchash, 3D, smeta*). The one exception is *ta’mir*: Apple may not match it to a search for ta'mir or tamir. If you want, swap it for *tamir*, the way people often type it (not standard spelling).
3. **The name METRX** may already be taken on the App Store. App Store Connect tells you when you create the app record. Fallbacks that still fit 30 characters: “METRX — Lazer o‘lchash” (22), “METRX Smeta” (11), “METRX Measure” (13).
4. **What the texts promise, and must stay true in the build you send:** no sign-up (the sign-in buttons must be removed, as decided), free with no purchases (the “METRX Pro” card must go), the ZB-08 laser connects, PDF quotes for the builder, Advanced mode for the other trades, four app languages.
5. **Promotional text** can be changed at any time without a new review; the rest changes only with a new version.
